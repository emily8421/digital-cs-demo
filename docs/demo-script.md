# Demo 演示脚本

> 数字客服 Demo 现场演示脚本：照着操作即可展示 P1 + P2（REQ-1~14）核心能力。
> 三个前端页面共用同一自建后端（FastAPI + pgvector + TEI）。

## 0. 前置

- **启动**：`docker compose -f docker/docker-compose.yml up -d`（db + TEI）+ `.venv/Scripts/python.exe -m uvicorn app.main:app --app-dir backend --host 0.0.0.0`
- **防火墙**（管理员 PowerShell，放行 8000 入站）：`netsh advfirewall firewall add rule name="DCS-H5-8000" dir=in action=allow protocol=TCP localport=8000 profile=any`
- **三个页面**（同一后端）：
  - `/ui` — PC 全功能控制台（演示者/深度）
  - `/ui/h5.html` — 客户视角 H5（扫码即聊）
  - `/ui/confirm.html` — 知识确认页面（拍板人）
- **手机扫码**：`http://<电脑局域网IP>:8000/ui/h5.html`（手机电脑同 WiFi；IP 用 `ipconfig` 查）

## 2. 场景二：员工 / 经营者侧（`/ui` 控制台）

PC 打开 `/ui`（左聊天 + 右控制台）。

- **转交通知**（REQ-5/8）：右侧「转人工转交」选场景（售前/待确认/订单/售后）+ 原因 → 看飞书卡片（送达角色 + 口语化提醒）。
- **经营者小结**（REQ-7）：点「生成经营者小结」→ "今天共 N 条客户消息…X 条需跟进：…均已通知对应同事"。
- **转人工暂停**（REQ-10）：「转人工暂停」填会话 ID 置 `handed_off` → **回 H5 发消息 → 无自动回复**（人工接管、AI 不抢话）；置 `auto` 恢复。

## 3. 场景三：知识回写闭环（`/ui/confirm.html`，REQ-13）

演示「知识库自增长」——答不上的问题，拍板人补答确认后，下次就能答。

1. **造缺口**：H5 发 `今天天气怎么样`（未命中）→ 客户侧"已请同事确认"。
2. **拍板人补答**：`/ui/confirm.html` 左侧「缺口补答」看到该缺口 → 填答案（如"灯饰客服不查天气，请看天气预报"）→ 点「补答 → 待确认」→ 进入右侧「待确认」。
3. **确认回写**：右侧点「确认 → 回写标准答案」→ confirmed + 缺口 resolved。
4. **验证自增长**：回 H5 再发 `今天天气怎么样` → 这次 AI 作答了（用刚补答的内容）。

## 4. 一键重放

H5 右上「▶ 演示」→ 自动跑：产品问答 → 缺口转人 → 留资 → 语音（约 10 秒展示主闭环）。
