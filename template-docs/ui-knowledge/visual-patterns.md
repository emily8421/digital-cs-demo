## 1. 模式清单

### PAT-VIS-001｜信息密度与层级

- **类型与维度**：Pattern / 视觉与布局
- **要解决的问题**：页面信息平铺，用户找不到重点。
- **建议**：用字号、字重、颜色和间距建立明确层级；区分标题、正文、辅助三级；相关内容分组；优先用留白分隔而非全是分割线。
- **适用条件**：内容型页面、管理后台、文档工作台。
- **不适用条件**：极简营销页（本就大留白，层级天然简单）。
- **行为契约**：不适用（纯视觉）。
- **视觉信号**：标题比正文大且重；辅助文字更浅更小；分组用留白或淡背景；首屏视觉层级重点不超过 3 个。
- **来源**：`SRC-DS-001`、`SRC-DS-002`；视觉案例候选 `SRC-VIS-001`
- **证据等级**：C
- **状态**：reviewed（2026-08-13）

### PAT-VIS-002｜数据密集表格展示

- **类型与维度**：Pattern / 视觉与布局、组件与表单行为
- **要解决的问题**：表格列多行密，难扫描、难对比。
- **建议**：固定表头 / 首列；行斑马或悬停高亮；数字右对齐、文本左对齐；关键列置左；提供筛选 / 排序 / 分页；详情走行内展开或侧抽屉。
- **适用条件**：后台管理、BI、issue tracker、数据网格。
- **不适用条件**：移动端窄屏（应转为卡片列表，而非压缩表格）。
- **行为契约**：不适用。
- **视觉信号**：表头粘顶；行高一致；数字右对齐；操作列固定右侧；空单元格显式标 `—` 而非留空。
- **来源**：成熟产品观察（多案例一致）；`SRC-DS-002`
- **证据等级**：C
- **状态**：reviewed（2026-08-13）

### PAT-VIS-003｜导航与信息架构

- **类型与维度**：Pattern / 信息架构与导航、视觉与布局
- **要解决的问题**：用户不知道自己在哪、能去哪。
- **建议**：持久主导航；当前位置高亮；面包屑显示路径；侧栏分类与页面标题一致；导航层级 ≤ 3 层。
- **适用条件**：多页面应用、管理后台、知识库。
- **不适用条件**：单页或线性流程型（步骤式不需要全局导航）。
- **行为契约**：不适用。
- **视觉信号**：当前导航项高亮；面包屑可点回上级；同级项视觉权重一致。
- **来源**：`SRC-DS-001`、`SRC-DS-002`
- **证据等级**：C
- **状态**：reviewed（2026-08-13）

### PAT-VIS-004｜首屏观感与扫描路径

- **类型与维度**：Pattern / 视觉与布局、产品与用户任务
- **要解决的问题**：首屏无法快速传达「这是什么、我能做什么」。
- **建议**：首屏突出核心价值与主行动；顺应常见扫描路径（F 型 / Z 型）；关键内容置于视觉重心。
- **适用条件**：落地页、产品首页、工具首屏。
- **不适用条件**：数据密集工作台（首屏是数据本身，不是营销）。
- **行为契约**：不适用。
- **视觉信号**：主标题与主按钮位于视觉重心；留白引导视线；首屏不堆满。
- **来源**：`SRC-VIS-001`（视觉启发，弱证据）
- **证据等级**：D
- **状态**：candidate（D 级证据最弱，待项目实证后再定升降）

### PAT-VIS-005｜配色与对比

- **类型与维度**：Pattern / 视觉与布局、可访问性与包容性
- **要解决的问题**：对比不足导致难读，或配色无体系、信息只靠颜色传达。
- **建议**：文本与背景对比度符合 WCAG（正常文本 ≥ 4.5:1，大文本 ≥ 3:1，非文本 UI 组件与图形 ≥ 3:1）；建立主色 / 辅色 / 语义色体系；不只靠颜色传达状态。
- **适用条件**：所有 Web UI（A 级基线）。
- **不适用条件**：无（对比度是基线要求）；纯装饰也建议纳入色板体系。
- **行为契约**：不适用（对比度可程序化检查，是验证项而非交互契约）。
- **视觉信号**：色板受限（主色 + 辅色 + 语义色）；提供暗色模式对照；错误 / 成功状态辅以图标或文字，不只红绿。
- **来源**：`SRC-A11Y-002`（WCAG 2.2）
- **证据等级**：A
- **状态**：reviewed（2026-08-13）

### PAT-VIS-006｜响应式断点

- **类型与维度**：Pattern / 响应式动效与感知性能、视觉与布局
- **要解决的问题**：同一界面在不同设备变形、错位或关键内容不可达。
- **建议**：定义断点体系；移动优先或桌面优先保持一致；关键内容在所有断点可达；触控目标 ≥ 44px。
- **适用条件**：跨设备 Web。
- **不适用条件**：固定设备（POS、自助终端、单屏 kiosk）。
- **行为契约**：不适用。
- **视觉信号**：断点处布局重排（而非只缩放）；移动端导航收起；窄屏表格转卡片。
- **来源**：成熟产品观察（多案例一致）
- **证据等级**：C
- **状态**：reviewed（2026-08-13）

## 2. 使用说明

- 视觉模式（除 `PAT-VIS-005` 等可访问性规范外）多为 C / D 级，**只用于视觉方向启发**，不得作为交互决策或用户研究证据。
- `SRC-VIS-001`（awesome-design-md）可作为视觉案例候选池，但抽取具体案例时默认 D 级，且不镜像其第三方素材（见 `README.md` §7）。
- 项目参考分析引用本文件模式时使用 `PAT-VIS-NNN` ID；项目级采纳 / 调整 / 排除决定写入项目自己的参考分析，不回写本文件。
- 视觉信号字段映射到 UI brief、视觉探索或 experience brief 的视觉方向；正式视觉规范仍以项目设计为准。
